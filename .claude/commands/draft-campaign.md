# /draft-campaign

Create an internal review draft from recorded campaign results. Do not send it.

Read CLAUDE.md and docs/compliance.md. Run npm run marketing -- draft-campaign with the named flags shown by npm run marketing -- help.

Flags: --campaign. Every command accepts --json.

Report the actual output and any missing evidence. Resolve names case-insensitively or use id prefixes. An ambiguous match must be clarified with the listed candidates. Never send, schedule or upload an audience.
